## Price assets (recommendation: "Add price assets", +2.5 %)

Form settings (Recommendations → "Add price assets" → the form opens with five rows):

| Field | Set to | Note |
|---|---|---|
| Language | English | default |
| Type | **Products** | the form defaults to **Brands**; change it, or the preview reads "Brand 1 / Brand 2" |
| Currency | USD | default |
| Price qualifier | **From** | "No qualifier" implies a fixed price; custom emblems vary by size and finish |
| Header | product name, ≤ 25 chars | |
| Price | starting price, **No units** | keep "No units"; "per hour / per day" are for services |
| Description | ≤ 25 chars | |
| Final URL | the product or configurator page | not the homepage or About page |
| Mobile final URL | leave blank | same page serves both |

Fill the prices from your store; three rows minimum (delete the empty extra rows before Apply),
up to eight.

| Header (≤ 25) | Description (≤ 25) | Price | Final URL |
|---|---|---|---|
| Custom Car Emblem | Your text, any finish | From $__ | configurator URL |
| Custom Grill Badge | Front grille emblem | From $__ | grill badge product URL |
| Custom Truck Emblem | Tailgate & fender badges | From $__ | truck product URL |
| Custom Metal Decal | Metal decal, any size | From $__ | decal product URL |

Price assets show real numbers in the ad and pre-qualify the click, which lowers CPA on the
85 % mobile traffic.

## Business name and logo

The ad preview shows the placeholder "**Business Name**". Assets → Business name → `Badge My Auto`.
Assets → Business logo → square PNG, 1:1, ≥ 1200 × 1200, plain background. Both require the
account to be verified under Advertiser verification; start that now if it is pending.

## Image assets

Add 4+ images (1.91:1 and 1:1) of finished emblems on cars, no text overlay. Image assets lift
mobile CTR and are a prerequisite for some ad formats.

## Promotion asset (seasonal)

If you run a discount, use a Promotion asset rather than putting the offer in a headline; it
is shown in its own line and can be scheduled.

## Lead-form / call assets

Skip "Add a phone number" unless someone answers during 6–10 AM weekdays (your best window).
An unanswered call asset costs clicks.
